# SYJ Video Forge v0.1.0 — PRE-RELEASE
**Foundation only; not a video-generation engine.**

Included: text/image form, prompt and image validation, image preview, duration through 30 seconds, seed/ratio, progress/status/cancel UI, provider disclosure, mock simulation, optional HTTP client, metadata-only history, long-video storyboard, docs, local servers, tests, and CI/Pages workflows.

Not included: real inference, model weights, Python backend, GPU worker, notebook tunnel, queue, ffmpeg stitching, cloud storage, telemetry, ads, trackers, or mandatory paid service. Thirty-second generation is a design target only.

Run `sh scripts/verify.sh` or `./scripts/verify.ps1`. Browser-specific CORS/PNA behavior and model inference were not validated by this foundation release.
